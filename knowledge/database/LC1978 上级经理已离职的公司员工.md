# LC1978 上级经理已离职的公司员工

这题的核心不是“找到了谁”，而是：

> **找一个关联对象已经不存在的记录。**

假设：

- `e` = 员工
- `m` = 经理
- `e.manager_id` 指向经理的 `employee_id`

如果员工还在表里，但他的 `manager_id` 对应不到任何当前员工记录，就说明这个经理已经离职。

---

## 写法一：LEFT JOIN + IS NULL

```sql
SELECT e.employee_id
FROM Employees e
LEFT JOIN Employees m
ON e.manager_id = m.employee_id
WHERE e.salary < 30000
  AND e.manager_id IS NOT NULL
  AND m.employee_id IS NULL
ORDER BY e.employee_id;
```

理解：

```text
员工 e.manager_id
    ↓
LEFT JOIN 去找经理 m.employee_id
    ↓
如果找不到
    ↓
m.employee_id = NULL
```

所以：

```sql
m.employee_id IS NULL
```

就代表经理记录不存在。

---

## 写法二：NOT IN

```sql
SELECT employee_id
FROM Employees
WHERE salary < 30000
  AND manager_id IS NOT NULL
  AND manager_id NOT IN (
      SELECT employee_id
      FROM Employees
  )
ORDER BY employee_id;
```

意思是：

```text
当前员工的 manager_id
    ↓
不在当前所有 employee_id 这个集合里
    ↓
经理已经离职
```

可以记：

> `NOT IN` = 不在这个集合里。

---

## 写法三：NOT EXISTS

```sql
SELECT e.employee_id
FROM Employees e
WHERE e.salary < 30000
  AND e.manager_id IS NOT NULL
  AND NOT EXISTS (
      SELECT 1
      FROM Employees m
      WHERE m.employee_id = e.manager_id
  )
ORDER BY e.employee_id;
```

理解：

```text
对当前员工 e
    ↓
去 Employees 里找他的经理
    ↓
如果一行都找不到
    ↓
NOT EXISTS = true
```

这里的：

```sql
SELECT 1
```

并不是要真的查询数字 1，而是 `EXISTS / NOT EXISTS` 只关心：

> **有没有满足条件的记录存在。**

---

## 三种写法怎么记

```text
LEFT JOIN + IS NULL
= 关联时没连上

NOT IN
= 不在这个集合里

NOT EXISTS
= 根本不存在满足条件的那一行
```

这三种本质都是在解决：

> **查“没有对应关联记录”的数据。**

面试或做题时，`NOT EXISTS` 的语义通常最直接；如果题目本身就是“左表保留，找右表不存在”，`LEFT JOIN + IS NULL` 也非常自然。
