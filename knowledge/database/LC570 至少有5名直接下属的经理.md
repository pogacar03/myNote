# LC570 至少有 5 名直接下属的经理

## 核心

这题重点记 `HAVING`：

```sql
SELECT a.name
FROM Employee a
JOIN Employee b
ON a.id = b.managerId
GROUP BY a.id, a.name
HAVING COUNT(*) >= 5;
```

### 为什么用 HAVING？

```text
WHERE   → 分组前过滤普通行
HAVING  → 分组后过滤聚合结果
```

这里 `COUNT(*)` 是 `GROUP BY` 之后得到的聚合结果，所以必须写：

```sql
HAVING COUNT(*) >= 5
```

不能写：

```sql
WHERE COUNT(*) >= 5
```

## 题型模板

```text
先 GROUP BY
再根据 COUNT / AVG / MAX / MIN 筛选
→ 用 HAVING
```
