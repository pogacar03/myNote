# LC1581 进店却未进行过交易的顾客

### 答案

```sql
SELECT customer_id, COUNT(*) AS count_no_trans
FROM Visits v
LEFT JOIN Transactions t
ON v.visit_id = t.visit_id
WHERE amount IS NULL
GROUP BY customer_id;
```

### 核心思路

`Visits` 是必须全部保留的表，因此放在 `LEFT JOIN` 左边。

```text
Visits
   ↓ LEFT JOIN
Transactions
   ↓
没有匹配到交易的 visit
→ 右表字段为 NULL
   ↓
WHERE amount IS NULL
   ↓
按 customer_id 分组
   ↓
COUNT(*) 统计每个顾客没有交易的访问次数
```

### 模板

```sql
SELECT 左表分组字段, COUNT(*)
FROM 左表
LEFT JOIN 右表
ON 连接条件
WHERE 右表字段 IS NULL
GROUP BY 左表分组字段;
```

> 更通用的写法通常优先判断右表的非空主键，例如 `WHERE t.transaction_id IS NULL`，因为它能更明确地表达“右表没有匹配到记录”。
