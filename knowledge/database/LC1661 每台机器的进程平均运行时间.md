# LC1661 每台机器的进程平均运行时间

## 核心思路

这题主要是把同一个 `machine_id + process_id` 的 `start` 和 `end` 两条记录通过自连接配对，然后计算一次进程耗时，最后按机器求平均。

```sql
SELECT a.machine_id,
       ROUND(AVG(b.timestamp - a.timestamp), 3) AS processing_time
FROM Activity a
JOIN Activity b
ON a.machine_id = b.machine_id
AND a.process_id = b.process_id
AND a.activity_type = 'start'
AND b.activity_type = 'end'
GROUP BY a.machine_id;
```

## 记忆点

```text
a = start 记录
b = end 记录

同一 machine_id
+ 同一 process_id
        ↓
把 start / end 配成一对
        ↓
b.timestamp - a.timestamp
        ↓
得到一次进程耗时
        ↓
GROUP BY machine_id
        ↓
AVG(...)
```

- 同表中的两类记录要配对：`Self Join`
- 平均耗时：`AVG(end.timestamp - start.timestamp)`
- 保留 3 位小数：`ROUND(..., 3)`
