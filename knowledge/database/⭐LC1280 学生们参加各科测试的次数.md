# ⭐LC1280 学生们参加各科测试的次数

### 题目核心

这题难点不是普通 `JOIN`，而是：**即使某个学生某个科目一次考试都没参加，也必须返回这一行，并显示 0。**

所以不能直接从 `Examinations` 出发，因为没参加考试的组合根本不存在。

### 正确思路

先生成：

```text
Students × Subjects
        ↓
得到所有 学生-科目 组合
        ↓
LEFT JOIN Examinations
        ↓
有考试记录就匹配
没考试记录就补 NULL
        ↓
COUNT(e.subject_name)
```

### SQL

```sql
SELECT
    s.student_id,
    s.student_name,
    sub.subject_name,
    COUNT(e.subject_name) AS attended_exams
FROM Students s
CROSS JOIN Subjects sub
LEFT JOIN Examinations e
ON e.student_id = s.student_id
AND e.subject_name = sub.subject_name
GROUP BY
    s.student_id,
    s.student_name,
    sub.subject_name
ORDER BY
    s.student_id,
    sub.subject_name;
```

### 关键点

#### 1. `CROSS JOIN`

```sql
Students s
CROSS JOIN Subjects sub
```

用于生成所有：

```text
学生 × 科目
```

也就是笛卡尔积。

#### 2. 为什么还要 `LEFT JOIN Examinations`

因为每个学生-科目组合都必须保留。

```text
Students × Subjects
        ↓
LEFT JOIN Examinations
```

如果没参加考试，右表 `e` 的字段就是 `NULL`。

#### 3. 为什么不能用 `COUNT(*)`

```sql
COUNT(*)
```

会把 `LEFT JOIN` 后那一行也算进去，因此没考试可能会被算成 1。

应该写：

```sql
COUNT(e.subject_name)
```

因为 `COUNT(column)` 不统计 `NULL`，没考试时正好得到 0。

#### 4. 展示科目名要用 `sub.subject_name`

```sql
sub.subject_name
```

不能写：

```sql
e.subject_name
```

因为没参加考试时 `e.subject_name = NULL`，但题目仍然要求显示科目名。

### 最终模板

```text
要求所有 A × B 组合都出现
即使明细表没有记录也要显示 0
        ↓
CROSS JOIN A,B
        ↓
LEFT JOIN 明细表
        ↓
COUNT(右表非空字段)
```

这题重点复习：`CROSS JOIN + LEFT JOIN + COUNT(column)`。
