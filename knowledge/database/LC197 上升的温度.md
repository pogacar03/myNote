# LC197 上升的温度

## 核心

这题主要就是要知道 `DATEDIFF`。

用同一张 `Weather` 表做自连接，把“今天”和“昨天”拼起来：

```sql
SELECT a.id
FROM Weather a
INNER JOIN Weather b
ON DATEDIFF(a.recordDate, b.recordDate) = 1
WHERE a.temperature > b.temperature;
```

## 关键点

```sql
DATEDIFF(a.recordDate, b.recordDate) = 1
```

表示：

> `a` 比 `b` 晚 1 天，也就是 `a = 今天`，`b = 昨天`。

然后：

```sql
a.temperature > b.temperature
```

表示今天温度高于昨天。

不要用：

```sql
a.id - 1 = b.id
```

因为题目要求比较的是日期是否连续，`id` 不保证连续。

## 心智模型

```text
同一张表前后两天比较
→ Self Join
→ DATEDIFF(...)=1 找相邻日期
→ WHERE 比较两天字段
```
