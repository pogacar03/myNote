# 回溯错误、速查

## 1. 组合题递归参数写错

典型：LC77 组合

错误：

```java
backtrack(n, k, start + 1);
```

正确：

```java
backtrack(n, k, i + 1);
```

原因：

当前这一层真正选中的是 `i`，所以下一层应该从 `i + 1` 开始。

口诀：

```text
选了谁，就从谁后面继续。
```

---

## 2. 数组有重复元素，却漏了“同层去重”

典型：

- LC40 组合总和 II
- LC90 子集 II

必须先排序：

```java
Arrays.sort(nums);
```

然后循环里加：

```java
if (i > start && nums[i] == nums[i - 1]) {
    continue;
}
```

口诀：

```text
数组有重复 + 答案不能重复
= 排序 + 同层去重
```

注意一定是：

```java
i > start
```

不是：

```java
i > 0
```

因为：

```text
树层去重，树枝不去重。
```

---

## 3. 组合题通常不需要 used

如果已经写：

```java
for (int i = start; i < n; i++)
```

并且递归：

```java
backtrack(..., i + 1);
```

那么：

```java
boolean[] used;
```

通常就是多余的。

速记：

```text
组合 / 子集 → start

排列 → used
```

本质：

```text
start：下一层从哪里开始选

used：当前路径中哪些下标已经被占用
```

---

## 4. LC40：每个元素只能用一次

LC40：

```java
backtrack(candidates, target - candidates[i], i + 1);
```

注意是：

```java
i + 1
```

不是：

```java
i
```

因为 LC40 中每个下标只能使用一次。

对比 LC39：

```java
backtrack(candidates, target - candidates[i], i);
```

速记：

```text
LC39：可以重复选 → i

LC40：不能重复选 → i + 1
```
