# 子集怎么用回溯生成？

对应 LeetCode 78：Subsets。

## 题型识别

看到“从数组里选任意若干个元素，要求返回所有可能组合/子集”，优先想到回溯。

核心结构：

```text
做选择
→ 递归
→ 撤销选择
```

## 标准代码

```java
class Solution {
    List<List<Integer>> res = new ArrayList<>();
    List<Integer> path = new ArrayList<>();

    public List<List<Integer>> subsets(int[] nums) {
        dfs(nums, 0);
        return res;
    }

    public void dfs(int[] nums, int start) {
        res.add(new ArrayList<>(path));

        for (int i = start; i < nums.length; i++) {
            path.add(nums[i]);
            dfs(nums, i + 1);
            path.remove(path.size() - 1);
        }
    }
}
```

## 关键点

### 1. 为什么每次递归都要把 path 放进 res？

因为当前 `path` 本身就是一个合法子集，包括空集 `[]`。

### 2. 为什么递归是 `dfs(nums, i + 1)`，不是 `start + 1`？

当前真正选择的是下标 `i`，下一层只能从 `i + 1` 继续往后选。

错误写法：

```java
dfs(nums, start + 1);
```

这样当当前 `i` 已经走得比 `start` 远时，会重新回到前面的区间，产生错误组合。

### 3. 为什么要撤销选择？

```java
path.remove(path.size() - 1);
```

递归回来后，要把刚才加入的元素删掉，恢复到进入这一层之前的状态，才能继续尝试下一个分支。

## 面试记忆版

