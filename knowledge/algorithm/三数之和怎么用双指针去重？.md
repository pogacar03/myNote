# 三数之和怎么用双指针去重？

## 题目

LeetCode 15：三数之和。

目标：在数组中找到所有满足：

```text
nums[a] + nums[b] + nums[c] = 0
```

且三元组不能重复。

---

## 核心思路

先排序，然后固定第一个数 `f1`，剩下两个数用左右双指针：

```text
f1 = i
f2 = i + 1
f3 = n - 1
```

因为数组已经有序：

```text
sum < 0  -> 和太小 -> f2++，让数变大
sum > 0  -> 和太大 -> f3--，让数变小
sum == 0 -> 收答案，然后继续移动 f2 / f3
```

本质：

> 排序 + 固定一个数 + 剩余两个数做双指针 Two Sum。

---

## 为什么 F1、F2、F3 都需要考虑去重？

### 1. F1 去重

```java
if (i > 0 && nums[i] == nums[i - 1]) {
    continue;
}
```

作用：避免用相同的值重复开启一轮搜索。

例如：

```text
[-1, -1, 0, 1]
 ↑    ↑
```

第一个 `-1` 已经把以 `-1` 为第一个数的所有组合找完了，第二个 `-1` 就没必要再做一次。

---

### 2. F2 / F3 去重

只给 `F1` 去重还不够。

反例：

```text
[-2, 0, 0, 2, 2]
```

第一次：

```text
F1 = -2
F2 = 第一个 0
F3 = 最后一个 2

=> [-2, 0, 2]
```

如果找到答案后只做：

```java
f2++;
f3--;
```

下一次：

```text
F1 = -2
F2 = 第二个 0
F3 = 前一个 2

=> [-2, 0, 2]
```

虽然下标不同，但三元组的值完全一样。

所以：

```text
F1 去重：避免重复开启相同的一轮搜索
F2/F3 去重：避免同一个 F1 下产生重复三元组
```

## 标准代码

```java
class Solution {
    public List<List<Integer>> threeSum(int[] nums) {

        Arrays.sort(nums);

        List<List<Integer>> res = new ArrayList<>();

        int n = nums.length;

        // 全正或者全负，直接不可能
        if (nums[0] > 0 || nums[n - 1] < 0) {
            return res;
        }

        for (int i = 0; i < n - 2; i++) {

            // F1 去重
            if (i > 0 && nums[i] == nums[i - 1]) {
                continue;
            }

            // 排序后 nums[i] > 0，后面只会更大
            if (nums[i] > 0) {
                break;
            }

            int f1 = i;
            int f2 = f1 + 1;
            int f3 = n - 1;

            while (f2 < f3) {

                int sum = nums[f1] + nums[f2] + nums[f3];

                if (sum == 0) {

                    res.add(Arrays.asList(
                        nums[f1],
                        nums[f2],
                        nums[f3]
                    ));

                    // F2 去重
                    while (f2 < f3 && nums[f2] == nums[f2 + 1]) {
                        f2++;
                    }

                    // F3 去重
                    while (f2 < f3 && nums[f3] == nums[f3 - 1]) {
                        f3--;
                    }

                    f2++;
                    f3--;

                } else if (sum < 0) {

                    // 和太小，让左边变大
                    f2++;

                } else {

                    // 和太大，让右边变小
                    f3--;
                }
            }
        }

        return res;
    }
}
```

---

## 为什么找到答案后 F2、F3 都要移动？

当：

```text
nums[f1] + nums[f2] + nums[f3] = 0
```

当前这一对 `f2 / f3` 已经记录过了。

继续寻找新答案时，需要换新的左右值，所以处理完重复元素以后：

```java
f2++;
f3--;
```

---

## 能不能不手动给 F2 / F3 去重，最后放 Set？

可以。

因为数组已经排序，所以每次得到的三元组内部顺序固定，可以使用：

```java
Set<List<Integer>> set = new HashSet<>();
```

找到答案：

```java
set.add(Arrays.asList(nums[i], nums[left], nums[right]));
```

最后：

```java
return new ArrayList<>(set);
```

这种写法能保证结果正确，但是属于：

> 重复答案先算出来，再让 Set 扔掉。

标准手动去重属于：

> 已经知道这些值会重复，所以直接跳过去，不再重复计算。

面试时优先写手动去重版本。

注意：不要使用 `Set<int[]>` 做内容去重，因为 Java 数组默认按对象引用比较；应该使用 `Set<List<Integer>>`。

## 面试记忆版

```text
排序
↓
固定 F1
↓
F2 = F1 + 1，F3 = n - 1
↓
while F2 < F3

sum < 0：F2++
sum > 0：F3--
sum = 0：收答案 -> F2/F3 去重 -> 两边继续移动
```

一句话：

> 固定一个，剩下两个左右夹逼；小了左移，大了右移，等于 0 收答案并去重。

时间复杂度：`O(n^2)`；排序为 `O(n log n)`，外层枚举与内部双指针整体为 `O(n^2)`。
