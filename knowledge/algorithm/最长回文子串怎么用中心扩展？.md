# 最长回文子串怎么用中心扩展？

对应 LeetCode 5：Longest Palindromic Substring。

## 题型识别

看到“最长回文子串”，面试里优先想到中心扩展法。

一个回文串的中心有两种：

```text
奇数长度：中心是一个字符，例如 aba
偶数长度：中心是两个字符之间，例如 abba
```

所以每个位置 i 都要尝试两次：

```java
expand(s, i, i);      // 奇数中心
expand(s, i, i + 1);  // 偶数中心
```

## 自己写的版本（重点记录）

这个版本和标准写法区别：

- 在 while 扩展过程中直接更新答案；
- 不需要退出循环后再计算 `right - left - 1`；
- 记录当前合法回文长度：`right - left + 1`。

```java
class Solution {
    int start = 0;
    int maxLen = 0;

    public String longestPalindrome(String s) {
        for (int i = 0; i < s.length(); i++) {
            expand(s, i, i);
            expand(s, i, i + 1);
        }
        return s.substring(start, start + maxLen);
    }

    public void expand(String s, int left, int right) {
        // 左右字符相等，并且没有越界，就继续扩展
        while (left >= 0 && right < s.length()
                && s.charAt(left) == s.charAt(right)) {

            if (right - left + 1 > maxLen) {
                maxLen = right - left + 1;
                start = left;
            }

            left--;
            right++;
        }
    }
}
```

## 两种写法区别

### 写法一：退出后计算

```java
int len = right - left - 1;
start = left + 1;
```

因为 while 退出时左右指针已经多走了一步。

### 写法二：扩展过程中计算（自己的版本）

```java
right - left + 1
```

因为此时 `left/right` 仍然在合法回文范围内。

## 易错点

- 偶数中心不需要提前判断两个字符是否相同，直接 `expand(i, i + 1)`。
- 扩展条件：

```java
left >= 0 && right < s.length()
&& s.charAt(left) == s.charAt(right)
```

- 不要忘记两个中心都要尝试。

## 一句话记忆

```text
每个位置尝试两个中心：
expand(i,i)
expand(i,i+1)

左右相等继续扩，扩展过程中维护最大长度。
```
