# 最长回文子串怎么用中心扩展？

对应 LeetCode 5：Longest Palindromic Substring。

## 题型识别

看到“最长回文子串”，面试里优先想到中心扩展法。

一个回文串的中心有两种：

```text
奇数长度：中心是一个字符，例如 aba
偶数长度：中心是两个字符之间，例如 abba
```

所以每个位置 i 都要尝试两次：

```java
expand(s, i, i);      // 奇数中心
expand(s, i, i + 1);  // 偶数中心
```

## 标准代码

```java
class Solution {
    int start = 0;
    int maxLen = 0;

    public String longestPalindrome(String s) {
        for (int i = 0; i < s.length(); i++) {
            expand(s, i, i);
            expand(s, i, i + 1);
        }

        return s.substring(start, start + maxLen);
    }

    public void expand(String s, int left, int right) {
        while (left >= 0 &&
               right < s.length() &&
               s.charAt(left) == s.charAt(right)) {
            left--;
            right++;
        }

        int len = right - left - 1;

        if (len > maxLen) {
            maxLen = len;
            start = left + 1;
        }
    }
}
```

## 关键点

### 1. 奇数中心和偶数中心

```java
expand(s, i, i);
expand(s, i, i + 1);
```

偶数中心不需要提前判断两个字符是否相同，直接进入 expand，由 while 条件判断即可。

### 2. 扩展条件

```java
while (left >= 0 && right < s.length()
        && s.charAt(left) == s.charAt(right))
```

停止条件本质上是：

```text
left < 0
或
right >= s.length()
或
s[left] != s[right]
```

注意右边界是 `right < s.length()`，不是等到 `right > n` 才停。

### 3. 为什么长度是 right - left - 1？

while 退出时，left 和 right 都已经各自多走了一步。

例如回文 `bab`：

```text
退出时：
left = -1
right = 3

真正回文区间是 [0, 2]
长度 = 3 - (-1) - 1 = 3
```

所以：

```java
int len = right - left - 1;
```

### 4. 为什么起点是 left + 1？

因为退出循环时 left 已经越过了真正回文的左边界一格，所以真实起点是：

```java
start = left + 1;
```
