# 每日温度为什么用单调栈？

对应 LeetCode 739：每日温度（Daily Temperatures）。

## 面试回答

这题要找每一天右边第一个更高温度，适合单调栈。

栈里存下标，不只存温度值，因为答案需要计算距离：

```text
等待天数 = 当前下标 i - 之前下标 idx
```

维护“对应温度单调递减”的栈。当前温度更高时，不断弹出栈顶；这些被弹出的元素此时第一次遇到右边更大的温度。

## 关键代码骨架

```java
int[] ans = new int[temperatures.length];
Deque<Integer> stack = new ArrayDeque<>();

for (int i = 0; i < temperatures.length; i++) {
    while (!stack.isEmpty()
            && temperatures[i] > temperatures[stack.peek()]) {

        int idx = stack.pop();
        ans[idx] = i - idx;
    }

    stack.push(i);
}
```

## 为什么当前更大时可以一直弹？

假设栈中对应温度是：

```text
75, 72, 69
```

新来 `73`：

```text
73 > 69 -> 69 出栈
73 > 72 -> 72 出栈
73 < 75 -> 停止
```

`69` 和 `72` 都第一次找到了右边比自己大的元素。

## 单调栈题型识别

看到这些描述优先想单调栈：

```text
右边第一个更大
右边第一个更小
左边第一个更大
左边第一个更小
每日温度
```

如果答案依赖位置/距离，栈中优先存下标。

## 一句话记忆

**新数更大，就把栈顶所有比它小的数弹掉；它们终于等到了右边第一个更大的数。**
