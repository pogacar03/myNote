# 怎么验证一棵二叉树是不是二叉搜索树？

## 对应题目

LeetCode 98 — 验证二叉搜索树

## 题型识别

看到“验证 BST / 二叉搜索树是否合法”，不能只比较父节点和直接孩子。

BST 的要求是：

- 当前节点左子树中的所有节点都必须 `< 当前节点`
- 当前节点右子树中的所有节点都必须 `> 当前节点`

所以递归时要给每个节点传一个合法区间 `(min, max)`。

## 核心思路

当前节点必须满足：

```java
min < root.val && root.val < max
```

往左子树走时：

```text
上界变成 root.val
(min, root.val)
```

往右子树走时：

```text
下界变成 root.val
(root.val, max)
```

## 为什么不能只比较父子节点？

例如：

```text
        5
       / \
      1   7
         / \
        4   8
```

局部父子关系：

```text
5 < 7   ✅
4 < 7   ✅
```

但 `4` 在根节点 `5` 的右子树中，却有 `4 < 5`，所以整棵树并不是 BST。

因此必须把祖先节点留下来的上下界约束继续传下去。

## 关键代码骨架

```java
class Solution {
    public boolean isValidBST(TreeNode root) {
        return dfs(root, Long.MIN_VALUE, Long.MAX_VALUE);
    }

    public boolean dfs(TreeNode root, long min, long max) {
        if (root == null) return true;

        if (root.val <= min || root.val >= max) {
            return false;
        }

        return dfs(root.left, min, root.val)
                && dfs(root.right, root.val, max);
    }
}
```

## 易错点：边界必须用 long

不要这样写：

```java
return dfs(root, Integer.MIN_VALUE, Integer.MAX_VALUE);
```

如果节点值本身就是：

```java
Integer.MIN_VALUE
```

那么：

```java
root.val <= min
```

会成立，错误返回 `false`。

所以初始化边界应使用：

```java
Long.MIN_VALUE
Long.MAX_VALUE
```

并且递归参数也写成：

```java
long min, long max
```

## 面试速记

```text

→ 每个节点带合法区间

右子树：(root.val, max)

初始边界一定用 long
```
