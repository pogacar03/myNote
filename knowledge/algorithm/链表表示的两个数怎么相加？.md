# 链表表示的两个数怎么相加？

对应 LeetCode 2：两数相加（Add Two Numbers）。

## 面试回答

两个链表按低位到高位逆序存数字，逐位相加并维护进位 `carry`。短链表走完后按 0 处理；即使两个链表都结束，只要 `carry != 0` 也要继续生成节点。

时间复杂度 `O(max(m,n))`，额外空间为结果链表。

## 关键代码骨架

```java
ListNode dummy = new ListNode(0);
ListNode cur = dummy;
int carry = 0;

while (l1 != null || l2 != null || carry != 0) {
    int x = l1 == null ? 0 : l1.val;
    int y = l2 == null ? 0 : l2.val;

    int sum = x + y + carry;

    cur.next = new ListNode(sum % 10);
    carry = sum / 10;

    cur = cur.next;

    if (l1 != null) l1 = l1.next;
    if (l2 != null) l2 = l2.next;
}

return dummy.next;
```

## 必须记住的简洁写法

### 1. while 条件不能漏 carry

```java
while (l1 != null || l2 != null || carry != 0)
```

否则 `99 + 1` 最后的百位 `1` 会丢掉。

### 2. 长度不一致不用写一堆 if

```java
int x = l1 == null ? 0 : l1.val;
int y = l2 == null ? 0 : l2.val;
```

### 3. 当前位与进位

```java
当前位 = sum % 10;
进位   = sum / 10;
```

## 一句话记忆

**短链表补 0；while 还要看 carry；当前位 `%10`，进位 `/10`。**
