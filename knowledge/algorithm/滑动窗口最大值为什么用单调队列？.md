# 滑动窗口最大值为什么用单调队列？

对应 LeetCode 239：滑动窗口最大值（Sliding Window Maximum）。

## 面试回答

这题要求每个固定窗口的最大值，不能每个窗口都重新扫描，否则是 `O(nk)`。

用 `Deque<Integer>` 存下标，并维护“对应值单调递减”的双端队列：

- 队头：当前窗口最大值下标。
- 队头过期：如果下标已经滑出窗口，删除。
- 队尾维护单调性：当前值更大时，把队尾更小的元素全部删除。

因为队尾那些元素“又小、又老”，以后不可能再成为窗口最大值，可以安全淘汰。

## 关键代码骨架

```java
Deque<Integer> deque = new ArrayDeque<>();
int[] ans = new int[nums.length - k + 1];

for (int i = 0; i < nums.length; i++) {

    // 1. 队头过期
    while (!deque.isEmpty()
            && deque.peekFirst() < i - k + 1) {
        deque.pollFirst();
    }

    // 2. 队尾维护单调递减
    while (!deque.isEmpty()
            && nums[deque.peekLast()] <= nums[i]) {
        deque.pollLast();
    }

    // 3. 当前下标入队
    deque.offerLast(i);

    // 4. 窗口形成后，队头就是最大值
    if (i + 1 >= k) {
        ans[i - k + 1] = nums[deque.peekFirst()];
    }
}
```

## 为什么存下标而不是值？

因为不仅要比较大小，还要知道元素是否过期。

当前窗口左边界：

```java
i - k + 1
```

如果：

```java
deque.peekFirst() < i - k + 1
```

说明队头已经不在当前窗口内。

## 一句话记忆

**单调队列存下标：队头管过期，队尾管淘汰；队尾比当前值小就是“又小又老，永无出头”。**
