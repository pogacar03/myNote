# 两个不相交链表的双指针为什么不会死循环？

## 面试回答

相交链表的双指针换头法中：

```text
pA 走 A -> B
pB 走 B -> A
```

两个指针最终都走了 `A.length + B.length` 的总路程。

如果相交，它们会在第一个公共节点相遇；如果不相交，它们最终会同时走到 `null`，因此循环也会结束，不会死循环。

## 关键代码

```java
public ListNode getIntersectionNode(ListNode headA, ListNode headB) {
    ListNode pA = headA;
    ListNode pB = headB;

    while (pA != pB) {
        pA = (pA == null) ? headB : pA.next;
        pB = (pB == null) ? headA : pB.next;
    }

    return pA;
}
```

## 易错点

判断相交比较的是节点对象本身：

```java
pA == pB
```

不是比较节点值：

```java
pA.val == pB.val
```

两个不同节点可以恰好拥有相同的值，但这不叫链表相交。

## 一句话记忆

**有交点就在交点相遇；没交点就在 null 相遇。**
