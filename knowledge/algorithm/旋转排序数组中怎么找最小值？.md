# 旋转排序数组中怎么找最小值？

对应 LeetCode 153：寻找旋转排序数组中的最小值（Find Minimum in Rotated Sorted Array）。

## 面试回答

旋转数组的最小值就是旋转点。推荐每轮拿 `nums[mid]` 和 `nums[right]` 比：

```text
nums[mid] > nums[right]
-> 最小值一定在 mid 右边
-> left = mid + 1

nums[mid] < nums[right]
-> 最小值在 mid 或 mid 左边
-> right = mid
```

最后 `left == right` 时就是最小值位置，时间复杂度 `O(log n)`。

## 推荐代码

```java
public int findMin(int[] nums) {
    int left = 0;
    int right = nums.length - 1;

    while (left < right) {
        int mid = left + (right - left) / 2;

        if (nums[mid] > nums[right]) {
            left = mid + 1;
        } else {
            right = mid;
        }
    }

    return nums[left];
}
```

## 为什么 `right = mid` 不是 `mid - 1`？

因为当 `nums[mid] < nums[right]` 时，`mid` 自己就可能是最小值，不能把它排除。

## 如果坚持和 left 比

和 `left` 比也能做，但必须先判断当前区间是不是已经完全递增：

```java
if (nums[left] < nums[right]) {
    return nums[left];
}
```

然后才能判断：

```java
if (nums[mid] >= nums[left]) {
    left = mid + 1;
} else {
    right = mid;
}
```

## 易错点

如果不先判断当前区间已经有序，直接看到 `nums[mid] > nums[left]` 就去右边，会在例如 `[1,2,3,4,5]` 中错误地丢掉真正的最小值 `1`。

## 一句话记忆

**和 right 比更稳；和 left 比之前先检查整段是否已经递增。**
