# 全排列怎么用回溯生成？

对应 LeetCode 46：Permutations。

## 当前薄弱点

这题能想到 `path`、`res`、`used[]` 和终止条件，但 **DFS 回溯主体没写出来**，后续需要重点复习下面这段骨架。

## 题型识别

看到“返回所有排列”，想到回溯。

和子集不同：
- 子集：下一层只能往后选，用 `start`。
- 全排列：每一层都要从 `0` 开始尝试所有数字，所以不用 `start`，改用 `used[]` 防止同一个元素重复使用。

## 标准代码

```java
class Solution {
    List<List<Integer>> res = new ArrayList<>();
    List<Integer> path = new ArrayList<>();

    public List<List<Integer>> permute(int[] nums) {
        boolean[] used = new boolean[nums.length];
        dfs(nums, used);
        return res;
    }

    public void dfs(int[] nums, boolean[] used) {
        if (path.size() == nums.length) {
            res.add(new ArrayList<>(path));
            return;
        }

        for (int i = 0; i < nums.length; i++) {
            if (used[i]) {
                continue;
            }

            path.add(nums[i]);
            used[i] = true;

            dfs(nums, used);

            path.remove(path.size() - 1);
            used[i] = false;
        }
    }
}
```

## 关键点

### 1. 为什么不需要 start？

因为排列和顺序有关。例如 `[1,2]` 和 `[2,1]` 都是合法答案，所以每一层都必须从下标 `0` 开始尝试。

### 2. 为什么要 used[]？

当前排列中，一个下标只能使用一次。

```java
if (used[i]) continue;
```

选中后：

```java
used[i] = true;
```

回溯回来：

```java
used[i] = false;
```

### 3. 什么时候加入结果？

只有当排列长度等于数组长度时，才得到一个完整排列：

```java
if (path.size() == nums.length) {
    res.add(new ArrayList<>(path));
    return;
}
```

## 和 LC78 子集对比

```text
LC78 子集：
for 从 start 开始
递归 dfs(i + 1)

LC46 全排列：
for 每次从 0 开始
使用 used[i] 防止重复使用
```
