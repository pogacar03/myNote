# 为什么快慢指针第二次相遇就是环入口？

## 面试回答

快慢指针第一次在环内相遇后，把其中一个指针放回 `head`，然后两个指针都改成每次走一步；它们再次相遇的位置就是环入口。

原因是：设 `head` 到环入口距离为 `a`，环入口到第一次相遇点距离为 `b`，相遇点沿环继续走到入口距离为 `c`，则环长为 `b + c`。

第一次相遇时：

```text
slow 距离 = a + b
fast 距离 = 2(a + b)
```

fast 比 slow 多走的是整数圈环长，因此：

```text
a + b = k(b + c)
```

整理：

```text
a = (k - 1)(b + c) + c
```

也就是说，从 head 走 `a` 步到入口；从第一次相遇点继续走 `a` 步，也会绕若干整圈后到入口。所以两个指针同步一步一步走，最终会在环入口相遇。

## 具体直觉例子

```text
1 -> 2 -> 3 -> 4 -> 5 -> 6 -> 7 -> 8
          ^                        |
          |________________________|
```

环入口是 `3`。如果第一次相遇在 `7`：

```text
head 到入口：1 -> 2 -> 3，2 步
相遇点到入口：7 -> 8 -> 3，2 步
```

所以一个回 head，一个留在相遇点，同时每次走一步，会在 `3` 相遇。

## 关键代码

```java
public ListNode detectCycle(ListNode head) {
    ListNode slow = head;
    ListNode fast = head;

    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;

        if (slow == fast) {
            ListNode p = head;

            while (p != slow) {
                p = p.next;
                slow = slow.next;
            }

            return p;
        }
    }

    return null;
}
```

## 一句话记忆

**第一次：快 2 慢 1 找相遇；第二次：一个回 head，两人都走 1，再相遇就是环入口。**
