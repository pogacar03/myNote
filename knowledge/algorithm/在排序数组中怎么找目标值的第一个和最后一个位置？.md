# 在排序数组中怎么找目标值的第一个和最后一个位置？

## 面试回答

这题不能在二分第一次命中 `target` 时直接返回，而是要做两次边界二分：

- 找左边界：命中后先记录答案，再继续向左二分。
- 找右边界：命中后先记录答案，再继续向右二分。

时间复杂度 `O(log n)`，不能命中后再线性向两边扫描，否则最坏会退化成 `O(n)`。

## 核心思路

普通二分：

```text
找到 target -> return
```

左边界二分：

```text
找到 target -> 记录 mid -> right = mid - 1
```

右边界二分：

```text
找到 target -> 记录 mid -> left = mid + 1
```

## 关键代码

```java
private int findLeft(int[] nums, int target) {
    int left = 0, right = nums.length - 1;
    int ans = -1;

    while (left <= right) {
        int mid = left + (right - left) / 2;

        if (nums[mid] == target) {
            ans = mid;
            right = mid - 1;
        } else if (nums[mid] < target) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }
    return ans;
}
```

找右边界时只改命中后的方向：

```java
if (nums[mid] == target) {
    ans = mid;
    left = mid + 1;
}
```

## 易错点

不要这样做：

```text
二分找到一个 target
-> while 向左扫描
-> while 向右扫描
```

这样最坏复杂度是 `O(n)`。

## 一句话记忆

**找左边界：找到也往左走；找右边界：找到也往右走。**
