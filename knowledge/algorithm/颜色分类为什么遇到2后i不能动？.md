# LC75 颜色分类：为什么遇到 2 后 i 不能动？

## 题目核心

数组中只有 `0、1、2`，要求原地排序成：

```text
0 0 0 1 1 1 2 2 2
```

经典解法是三指针，也叫荷兰国旗问题。

## 指针含义

```java
int left = 0;               // 下一个 0 应该放的位置
int i = 0;                  // 当前扫描位置
int right = nums.length - 1;// 下一个 2 应该放的位置
```

数组始终可以理解成四段：

```text
[0区域 | 1区域 | 未处理区域 | 2区域]
```

更精确地说：

```text
[0, left - 1]       全是 0
[left, i - 1]       全是 1
[i, right]          还没处理
[right + 1, n - 1]  全是 2
```

## 模板代码

```java
class Solution {
    public void sortColors(int[] nums) {

        int left = 0;
        int i = 0;
        int right = nums.length - 1;

        while (i <= right) {

            if (nums[i] == 0) {
                swap(nums, i, left);
                left++;
                i++;

            } else if (nums[i] == 2) {
                swap(nums, i, right);
                right--;

                // 注意：这里不能 i++

            } else {
                // nums[i] == 1
                i++;
            }
        }
    }

    private void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }
}
```

## 为什么遇到 2 后，i 不能动？

例如：

```text
[1, 2, 0]
    ↑     ↑
    i   right
```

当前 `nums[i] == 2`，把它和 `right` 交换：

```text
[1, 0, 2]
    ↑
    i
```

此时从右边换过来的数是 `0`，它之前属于“未处理区域”，所以还没有检查过。

因此：

```java
right--;
```

之后，`i` 必须留在原地，再检查一次当前位置。

所以不能写：

```java
right--;
i++; // 错误
```

## 为什么遇到 0 后可以 i++？

```java
if (nums[i] == 0) {
    swap(nums, i, left);
    left++;
    i++;
}
```

因为 `left` 左边已经全是 0，而 `[left, i - 1]` 已经是处理好的 1 区域。

所以从 `left` 换到 `i` 的数，要么是已经确认过的 `1`，要么 `left == i`，本质上不需要重新检查。

因此可以直接 `i++`。

## 记忆口诀

> 0 往左扔，2 往右扔，1 原地跳过；遇到 2 交换后 i 不动。

## 复杂度

```text
时间复杂度：O(n)
空间复杂度：O(1)
```

只使用了 `left、i、right` 等常量个额外变量，所以是常量级空间。
