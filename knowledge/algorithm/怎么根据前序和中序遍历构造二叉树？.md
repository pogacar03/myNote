# LeetCode 105：怎么根据前序和中序遍历构造二叉树？

## 题型识别

看到：

- 前序遍历 `preorder`
- 中序遍历 `inorder`
- 要求还原二叉树

优先想到：**递归切分左右子树**。

## 核心结论

前序遍历顺序：

```text
根 -> 左 -> 右
```

所以当前 `preorder` 区间的第一个元素一定是当前子树根节点。

中序遍历顺序：

```text
左 -> 根 -> 右
```

因此只要在 `inorder` 中找到根的位置，就能把当前子树切成：

```text
inorder 左边 = 左子树
inorder 右边 = 右子树
```

例如：

```text
preorder = [3,9,20,15,7]
inorder  = [9,3,15,20,7]
```

`preorder[0] = 3`，所以根是 3。

在 `inorder` 中：

```text
[9] 3 [15,20,7]
```

因此左子树大小为 1。

那么 `preorder` 也可以按这个大小切：

```text
根：3
左子树 preorder：[9]
右子树 preorder：[20,15,7]
```

## 为什么要用 HashMap

如果每次递归都在线性扫描 `inorder` 找根位置，最坏会到 `O(n^2)`。

提前建立：

```java
Map<Integer, Integer> indexMap = new HashMap<>();
for (int i = 0; i < inorder.length; i++) {
    indexMap.put(inorder[i], i);
}
```

就能 `O(1)` 找到根在 `inorder` 中的位置，整体复杂度降为 `O(n)`。

## 推荐代码骨架

```java
class Solution {
    Map<Integer, Integer> indexMap = new HashMap<>();

    public TreeNode buildTree(int[] preorder, int[] inorder) {
        for (int i = 0; i < inorder.length; i++) {
            indexMap.put(inorder[i], i);
        }

        return dfs(preorder, 0, preorder.length - 1,
                   inorder, 0, inorder.length - 1);
    }

    private TreeNode dfs(int[] preorder, int preL, int preR,
                         int[] inorder, int inL, int inR) {

        if (preL > preR) return null;

        int rootVal = preorder[preL];
        TreeNode root = new TreeNode(rootVal);

        int rootIndex = indexMap.get(rootVal);
        int leftSize = rootIndex - inL;

        root.left = dfs(
                preorder,
                preL + 1,
                preL + leftSize,
                inorder,
                inL,
                rootIndex - 1
        );

        root.right = dfs(
                preorder,
                preL + leftSize + 1,
                preR,
                inorder,
                rootIndex + 1,
                inR
        );

        return root;
    }
}
```

## 最容易写错的地方

### 1. 左子树大小

```java
int leftSize = rootIndex - inL;
```

不是 `rootIndex` 本身，因为当前递归处理的 `inorder` 可能不是从 0 开始。

### 2. 左子树 preorder 区间

```text
[preL + 1, preL + leftSize]
```

### 3. 右子树 preorder 区间

```text
[preL + leftSize + 1, preR]
```

### 4. 递归结束条件

```java
if (preL > preR) return null;
```

## 面试一句话

**前序第一个是根；中序找到根后切出左右子树；左子树节点数决定 preorder 如何继续切分；用 HashMap 记录 inorder 下标可做到 O(n)。**
