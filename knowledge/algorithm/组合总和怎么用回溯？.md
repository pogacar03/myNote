# 组合总和怎么用回溯？

对应 LeetCode 39：Combination Sum。

## 题型识别

看到“从候选数组里选若干个数，使总和等于 target，并且同一个数字可以重复使用”，优先想到回溯。

可以把 `target` 设计成“当前还差多少”：

```java
currentNeed
```

每选一个数，就减掉它：

```java
dfs(candidates, currentNeed - candidates[i], i);
```

## 标准代码

```java
class Solution {
    List<List<Integer>> res = new ArrayList<>();
    List<Integer> path = new ArrayList<>();

    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        dfs(candidates, target, 0);
        return res;
    }

    public void dfs(int[] candidates, int currentNeed, int start) {
        if (currentNeed == 0) {
            res.add(new ArrayList<>(path));
            return;
        }

        if (currentNeed < 0) {
            return;
        }

        for (int i = start; i < candidates.length; i++) {
            path.add(candidates[i]);

            dfs(candidates, currentNeed - candidates[i], i);

            path.remove(path.size() - 1);
        }
    }
}
```

## 重点易错点

### 1. `currentNeed < 0` 直接 return

这是这次第一次重点遇到的剪枝写法：

```java
if (currentNeed < 0) {
    return;
}
```

含义：当前组合的和已经超过 target 了，这条分支继续往下搜也不可能变回合法答案，所以直接结束这条递归分支。

### 2. 不用 `used[]` 时，组合题通常需要 `start`

组合题里：

```text
[2,3]
[3,2]
```

本质是同一个组合，不能重复统计。

所以用 `start` 限制下一层只能从当前下标及其后面继续选，避免“往回选”。

例如：

```text
先选 2
→ 后面可以选 2、3、4...

先选 3
→ 后面只能选 3、4...
→ 不能再回头选 2
```

注意：这不是要求数值一定从小到大，而是要求“下标搜索方向不能往回走”。

### 3. 为什么递归传 `i`，不是 `i + 1`？

因为 LC39 允许同一个数字重复使用。

```java
dfs(candidates, currentNeed - candidates[i], i);
```

如果传 `i + 1`，当前数字下一层就不能再选，会漏掉：

```text
[2,2,3]
```

## 和前面回溯题对比

```text
LC78 子集：
用 start
下一层 dfs(i + 1)
因为当前元素只能用一次

LC46 全排列：
不用 start
每层从 0 开始
用 used[] 防止同一个下标重复使用

LC39 组合总和：
用 start 防止组合重复
下一层 dfs(i)
因为当前元素可以重复使用
```

## 面试记忆版

```text
组合总和：
need == 0：收答案
need < 0：剪枝 return
for 从 start 开始
    选择 candidates[i]
    dfs(need - candidates[i], i)
    撤销选择
```

关键代码：

```java
if (currentNeed == 0) {
    res.add(new ArrayList<>(path));
    return;
}
if (currentNeed < 0) return;

for (int i = start; i < candidates.length; i++) {
    path.add(candidates[i]);
    dfs(candidates, currentNeed - candidates[i], i);
    path.remove(path.size() - 1);
}
```
