# 循环数组怎么用单调栈找下一个更大元素？

对应 LeetCode 503：下一个更大元素 II（Next Greater Element II）。

## 面试回答

循环数组不需要真的复制一份数组。让下标 `i` 遍历 `0..2n-1`，真正访问的位置用：

```java
int idx = i % n;
```

这样就相当于虚拟走了两圈。

栈中存下标，维护单调递减；当前值更大时不断弹栈，并给被弹出的下标补上答案。

## 关键代码骨架

```java
int n = nums.length;
int[] ans = new int[n];
Arrays.fill(ans, -1);

Deque<Integer> stack = new ArrayDeque<>();

for (int i = 0; i < 2 * n; i++) {
    int idx = i % n;

    while (!stack.isEmpty()
            && nums[idx] > nums[stack.peek()]) {
        int oldIdx = stack.pop();
        ans[oldIdx] = nums[idx];
    }

    if (i < n) {
        stack.push(idx);
    }
}
```

## 为什么第二圈不再入栈？

第一圈负责把每个原始位置放进栈；第二圈只是为了让第一圈那些还没找到更大元素的位置继续“往数组开头找”。如果第二圈继续重复入栈，会产生重复下标和无意义处理。

## 易错点

- 遍历次数是 `2 * n`。
- 实际访问下标是 `i % n`。
- 第一圈入栈，第二圈只补答案。
- 默认答案先填 `-1`。

## 一句话记忆

**循环数组：走 2n 次，用 `% n` 映射；第一圈入栈，第二圈补答案。**
