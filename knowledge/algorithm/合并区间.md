# 合并区间

LeetCode 56：合并区间。

## 核心思路

先按照每个区间的左端点从小到大排序，然后用 `left` 和 `right` 维护当前正在合并的这一段区间。

```java
Arrays.sort(intervals, (a, b) -> a[0] - b[0]);
```

这里：

- `a[0]`：区间 `a` 的左端点
- `b[0]`：区间 `b` 的左端点
- `a[0] - b[0] < 0`：`a` 排在 `b` 前面

所以这行代码表示：

> 按照区间左端点升序排序。

---

## left / right 表示什么

```java
int left = intervals[0][0];
int right = intervals[0][1];
```

`left` 和 `right` 表示：

> 当前正在合并的这一整段区间的左右边界。

它们不一定只对应原数组里的某一个区间。

例如：

```text
[1,3] [2,6] [4,8]
```

开始：

```text
left = 1
right = 3
```

看到 `[2,6]`：

```text
2 <= 3
```

说明新区间和当前区间有重叠，所以只扩展右边界：

```java
right = Math.max(right, intervals[i][1]);
```

得到：

```text
[1,6]
```

再看到 `[4,8]`：

```text
4 <= 6
```

继续合并：

```text
[1,8]
```

---

## 什么时候结束当前这一段

如果：

```java
intervals[i][0] > right
```

说明新区间已经和当前 `[left, right]` 不重叠。

这时先保存当前这一段：

```java
res.add(new int[]{left, right});
```

然后让 `left / right` 开始维护下一段：

```java
left = intervals[i][0];
right = intervals[i][1];
```

所以整体状态流转就是：

```text
新区间左端点 <= right
    ↓
可以合并
    ↓
right = max(right, 新区间右端点)

新区间左端点 > right
    ↓
当前段结束
    ↓
保存 [left, right]
    ↓
left / right 重置为新区间
```

---

## 为什么循环结束后还要 add 一次

```java
res.add(new int[]{left, right});
```

循环中的 `res.add()` 只有在遇到下一段不重叠区间时才会触发。

最后一段后面已经没有新区间了，所以不会触发 `else`，必须在循环结束后手动加入结果。

## List<int[]> 怎么转成 int[][]

`res` 的类型是：

```java
List<int[]> res = new ArrayList<>();
```

最终题目要求返回：

```java
int[][]
```

可以直接写：

```java
return res.toArray(new int[res.size()][]);
```

记忆：

```text
List<int[]>  →  int[][]
res.toArray(new int[res.size()][])
```

## 完整代码

```java
class Solution {

    public int[][] merge(int[][] intervals) {

        if (intervals.length == 1) return intervals;

        Arrays.sort(intervals, (a, b) ->
            a[0] - b[0]
        );

        List<int[]> res = new ArrayList<>();

        int left = intervals[0][0];
        int right = intervals[0][1];

        for (int i = 1; i < intervals.length; i++) {

            if (intervals[i][0] <= right) {
                right = Math.max(right, intervals[i][1]);
            } else {
                res.add(new int[]{left, right});
                left = intervals[i][0];
                right = intervals[i][1];
            }
        }

        res.add(new int[]{left, right});

        return res.toArray(new int[res.size()][]);
    }
}
```

## 复杂度

排序：`O(n log n)`

扫描合并：`O(n)`

所以总时间复杂度：

```text
O(n log n)
```

## 一句话记忆

> 左端点排序 → `left/right` 维护当前段 → 能合并只扩 `right` → 不能合并就结算当前段 → 最后一段手动补 → `List<int[]>` 用 `toArray(new int[res.size()][])` 转成 `int[][]`。
